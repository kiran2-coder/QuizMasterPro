IV. Class Relationships Summary
----------------------------------------------------

- Inheritance: All Activities extend AppCompatActivity. All Adapters extend RecyclerView.Adapter.

- Association (Composition/Aggregation):
  - Activities often "have" Adapters (e.g., ManageUsersActivity has an AdminUserAdapter).
  - Adapters always "have" a collection of Model objects (e.g., UserAdapter has a List<UserModel>).
  - Activities often "have" instances of Firebase components (FirebaseAuth, FirebaseFirestore).

- Dependency:
  - Activities depend on other Activities for navigation (e.g., LoginActivity can start UserDashboardActivity).
  - Activities depend on Model classes to pass data (e.g., RegisterActivity creates a UserModel).
  - Adapters' ViewHolders depend on the XML layout files for UI element inflation.
  - Most classes that interact with Firebase have a dependency on FirebaseFirestore and FirebaseAuth.
